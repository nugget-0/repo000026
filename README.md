# Nugget Tac Toe

Tic tac toe, but it got way out of hand.

- **Everything**: endless board, 4 stacked 3D floors, chess pieces and UNO cards all at once.
- **Chaos Grid**: endless 2D board with knights, rooks and bishops that move and capture.
- **Cube 3D**: 3x3x3 or 4x4x4 cube where lines count in every direction.

Play vs bot (easy/normal/hard) or 2 players on one device. Single file: open `index.html`.
